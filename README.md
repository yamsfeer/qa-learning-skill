# qa-learning：快问快答学习法

> 一个"快速认识新领域 + 沉淀速查卡"的 AI 技能（Skill）。
> 给人看的说明文档；给 AI 看的规范在同目录 `SKILL.md`。

---

## 这是什么？

一套**快速学习新领域的方法论**，打包成一个 AI 可自动加载的 Skill。

当你面对一个新领域（比如向量数据库、语音识别、经济金融……）时，通常有两种学习方式：

| 方式 | 代价 | 结果 |
|---|---|---|
| 系统深入学习 | 大量时间 | 理解原理，但可能用不上那么多 |
| **快问快答（本 skill）** | 半小时对话 | 建立正确体感：能判断、能选型、能上手，还得到一张速查卡 |

本 skill 选择后者：**不求深入，但求"粗浅且正确"**——知道它是什么、有什么用、怎么选、怎么调，就够用了。原理部分用户说"放弃"就放弃。

---

## 为什么值得用？

- **面向真实需求**：多数时候你需要的不是"原理大师"，而是"够用的判断力"
- **体感优先**：用公式、刻度、比喻建立直觉（如"速度 ≈ 带宽 ÷ 体积"），而不是堆术语
- **沉淀可复用**：每次学习结束自动产出一张速查卡，长期查阅，越攒越多
- **场景普适**：技术领域（LLM、数据库、AI 框架）和非技术领域（金融、行业）都适用

---

## 怎么用？

### 对用户（一句话触发）
> "我们快问快答，帮我快速认识一下 X，最后整理成速查卡。"

AI 会自动执行五步流程：
1. 进入快问快答模式（简短回答：原因+结果）
2. 你一条条提问，它一条条答
3. 你复述理解，它纠偏确认
4. 结束时可要求：**"整理成速查卡，保存到我的笔记仓库"**
5. 它按规范生成 Q&A 格式的速查卡文件

### 对 AI（加载本 skill 后）
严格遵循 `SKILL.md` 中的：五步流程 → 回答规范 → 速查卡格式模板。
产出示例见 `examples/`。

---

## 目录结构

```
qa-learning/
├── SKILL.md                    ← 给 AI 的完整规范（自包含，可单独拿走使用）
├── README.md                   ← 本文件，给人看的说明
└── examples/
    └── 向量数据库速查卡.md      ← 成品示例：速查卡该长什么样
```

> **设计原则：SKILL.md 自包含**——即使只拿走 SKILL.md 一个文件，AI 也能独立执行整套方法（流程、规范、格式模板都写在里面）；examples/ 只是锦上添花的参考样例。

---

## 产出长什么样？

速查卡 = **Q&A 形式 + 表格 + 一句话总结**，按"先概念 → 后选型 → 再实践"组织。
完整样例请看 [`examples/向量数据库速查卡.md`](examples/向量数据库速查卡.md)。
